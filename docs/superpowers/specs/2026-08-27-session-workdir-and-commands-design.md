# 会话工作目录与聊天命令设计

## 目标

让用户在新建会话时从已有项目根目录继续进入任意子目录，将该目录作为仅属于该会话的 Claude 工作目录；同时提供 `/help`、`/status`、`/compact`，且上下文压缩不得删除手机端可阅读的消息历史。

## 范围与边界

- 子目录不是新项目，不新增项目记录，也不改变项目列表。
- 已有会话的工作目录为空，等同于项目根目录，保持兼容。
- `/compact` 转发给当前 Claude Code 会话；App 和 Gateway 均不删除或摘要已有消息。
- `/help` 与 `/status` 是 App 本地命令，不发起 Claude 回合。

## 数据与接口

1. `sessions` 新增可空 `working_directory` 字段，存储相对项目根目录的 POSIX 路径；根目录使用 `null`。
2. 创建会话请求、会话摘要和详情增加 `workingDirectory`；发送后续消息继续使用会话已保存的目录。
3. Gateway 提供或扩展安全目录解析：拒绝绝对路径、空段、`.`、`..`、NUL 字符和项目根目录外的真实路径；目标必须存在且为目录。

## 交互

新建会话页先选择项目，再点击“选择工作目录”。目录选择器从项目根目录开始，支持进入子目录、返回上一级、确认“使用当前目录”。确认后页面显示例如 `myclaude / apps/mobile`；选择根目录时显示“项目根目录”。

输入 `/` 显示全部内置命令。`/help` 展示可用命令及说明；`/status` 展示模型、模式、流式开关、Gateway 和工作目录；`/compact` 在聊天中作为用户消息发送到 Claude，并保留本地消息记录。其他 `/` 命令仍沿用技能选择和未支持提示。

## 错误处理与测试

目录在创建前被删除、不是目录或越界时，Gateway 返回可读错误且不创建会话。App 在选择器中保留用户当前位置并允许重新选择。

测试覆盖：根目录与合法深层目录创建会话；非法路径与软链接越界拒绝；旧会话默认为根目录；`/help`、`/status` 不创建 Claude 回合；`/compact` 后历史消息仍完整存在，后续回合使用同一工作目录。
